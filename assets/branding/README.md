# AURA branding set

The source artwork in this directory is intentionally vector-based so it can be exported without quality loss for Android, iOS, Google Play, App Store, website, and web-app use.

- `aura-full-logo.svg` — full logo with AURA wordmark and MUSIC & MEDIA tagline.
- `aura-app-icon.svg` — square launcher/store icon with the circular neon badge.
- `aura-splash-screen.svg` — portrait splash artwork.
- `branding-exports.json` — platform export names, sizes, and brand colors.

Use the full logo for website/store presentation and the app icon for launcher, favicon, PWA, Play Store, and App Store exports. Keep the dark background and preserve the clear space around the neon ring when rasterizing.
