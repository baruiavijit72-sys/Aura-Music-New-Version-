# 🎵 Aura Music

Aura Music is a fast, lightweight, and modern music player designed to deliver high-quality audio streaming and seamless local playback.

![Aura Music](https://aura-music-dev.netlify.app/logo.png)

---

## ✨ Features

- 🎧 **High-Quality Audio:** Smooth streaming and offline playback experience.
- ⚡ **Lightweight & Fast:** Optimized for performance with zero lag.
- 🎨 **Modern UI:** Clean, intuitive, and user-friendly interface.
- 💳 **In-App Subscription:** Easy subscription support powered by Razorpay.
- 🔒 **Privacy-Focused:** Safe and secure experience for all users.
